# Combined-objective plots

All generated multi-objective figures are organized here:

- `qa_random_20seeds/`: HotpotQA/MathQA random-search contact sheets, HV
  regret curves, and the seed-42 Gittins versus 20-seed random comparison.
- `scope_random/`: six-dataset SCOPE random-configuration and random-question
  contact sheets.
- `scope_gittins/`: six-dataset SCOPE Gittins figures after the running Slurm
  jobs complete.

Raw CSV files, compressed caches, wall-time records, and Slurm logs remain
under `analysis/vs/`.
